# Sesión 11 — Cuaderno de supuestos

`Sesion 11.xlsx` ya no es la plantilla municipal. Sigue el orden del cuaderno de referencia, con los 105 pares de la sesión 10.

La diferencia es postest − pretest del mismo lector. Como n = 105 es mayor que 50, la normalidad es Kolmogorov-Smirnov con corrección de Lilliefors (Monte Carlo, 20 000 réplicas, semilla 20261107). Shapiro-Wilk no se usó para decidir. Levene no se calculó: no hay grupo de comparación.

Con ese criterio, SUS va a Wilcoxon. TAM, tiempo de búsqueda y clics van a t de Student para muestras relacionadas. La ficha no trae el valor p de esa contrastación: eso queda para la sesión 12. El SUS del postest sigue siendo el simulado de la sesión 7.
